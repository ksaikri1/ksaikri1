## What I Build

### [Opinoz](https://opinoz.com) — Verified Review Platform
A Reddit-style community platform for honest, verified reviews of products, services, and employers.  
Built with React + Vite, Firebase, Cloudflare R2, and Vercel serverless functions.

> Community reviews · Upvotes · Employer ratings · Real identities

---

### [MySafeCard](https://mysafecard.in) — Emergency Digital ID
Solo-built multi-platform emergency identity product.  
Scan a QR code, tap NFC, or open the web link — your emergency details are instantly accessible.

> QR · NFC · Web · Google Auth · Firebase · Live users

---

### [ElitePass](https://elitepass.in) — Loyalty Subscription Platform
Co-founded and led initial development. Live with 10+ cafe partners.  
Customers pre-buy coffee bundles; cafes get guaranteed recurring footfall.

> 10+ partner cafes · Subscription model · React Native + Firebase

---

### [HealthieSpan](https://healthiespan.com) — Hospital Management System
Built this as a favour for a friend who runs a clinic — ended up being a full production system.  
Covers patient management, lab workflows, doctor consultations, prescriptions, and billing.

> Used by real clinics · End-to-end built from scratch
